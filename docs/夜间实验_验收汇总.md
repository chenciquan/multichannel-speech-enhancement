## 最重要的结果

**G3：完整组合不是全面胜出。**相对普通LoRA，三种子平均WER下降2.28个百分点，SI-SDR下降0.62dB；PESQ/STOI略有改善。按说话人等权后WER差异约−0.78个百分点，说明样本分布会影响总体结论。干净约束有一定波形保护作用，不能据此保证识别或音素同步改善。

**G4：方向敏感性值得研究。**保持人声与噪声相对方位的整体旋转对照中，普通适配在20°为4.00dB、−30°为−2.54dB，参考第5麦声音完全相同。适配收益明显依赖方向，但阵列各向异性仍存在，不能把原因全部归结为过拟合。

**G5：成熟的旋转增强修复了部分方向退化，同时产生代价。**下表为无干净约束、三种子平均的新说话人结果，单元格为SI-SDR dB / WER：

|目标方向|固定场景训练|整场景旋转训练|解读|
|---|---:|---:|---|
|−40°|−8.66 / 113.8%|1.48 / 62.7%|明显改善，但WER仍高，接近带噪输入62.6%|
|20°|6.20 / 29.1%|3.83 / 44.3%|原名义方向表现退步|
|70°|0.48 / 77.6%|0.49 / 81.8%|SI-SDR几乎不变，识别更差|

因此，非训练方向平均+5.07dB、WER下降23.40个百分点主要由−40°改善驱动，**不能写成各方向全面提升**。旋转加干净约束也没有消除全部权衡。干净输入波形改善不代表单一识别器的WER一定改善。

WER可因插入词超过100%，不是“人声丢失百分比”。本轮未新增人工听感结论，Whisper漏词或幻觉都不能直接证明声音被删除。

## 当前最推荐的路线

继续研究**空间条件变化下的轻量适配与语音保真权衡**，不回到未经证实的吞字恢复模块。将普通LoRA、分层采样和成熟整场景旋转增强作为强对照，再判断是否需要新方法。旋转增强、LoRA和干净重建均是已有思路，当前不作为原创算法宣称。

下一步先对照试听同一句在三个方向的固定/旋转输出，确认可听代价及ASR幻觉。若继续开发，应在验证集上研究如何兼顾20°保持与其他方向，另行冻结确认数据；不能拿已经查看的G3/G4/G5结果反复调参后继续称作独立测试。

三个最大风险：

1. 仅自由场名义阵列；G5仅0dB、三个新说话人，没有真实混响/硬件泛化证据。
2. 单一ASR、短句和少量说话人；WER与客观指标都不能代替人声细节的人工核查。
3. 方法组件已有先例，且收益有明显代价；创新性和整体优势尚未建立，不保证发表论文。
