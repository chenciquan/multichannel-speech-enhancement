# G23A 识别器增益敏感性控制协议

固定48条件：四源语音、两房间、请求RT=.15/.35、全部三个方向、OOFFICE点源相对−80。保留干净参考、带噪参考麦、正确刚性全部三种子的MVDR/MWF及两个真值诊断，共10种输出。选取基于场景标签，不按识别错误逐例挑选。

0dB复用原文件，−6/−12dB仅对整段乘固定正标量，存FLOAT WAV，不削波、不修复或重新推理。共480基准对，960新音频，1440评分/后端。浮点缩放往返相对误差≤1e−6；非干净参考SI-SDR差≤0.001dB。干净参考的理想SI-SDR比较退化，单列并只核对波形结构，所有ASR仍保留。

后续沿用固定双识别器，以同模型/PCM哈希复用缓存，0dB应全部命中已有缓存。比较S/D/I与假设文本变化，不根据结果选最佳增益。实验是评估器诊断，不是增强创新；降低播放电平可能影响人耳可听度，不声称听感不变。未实现或复现TSOS。
