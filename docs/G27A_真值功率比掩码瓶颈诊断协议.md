# G27A 真值功率比掩码瓶颈诊断协议

复用 G22 全部432个带噪条件，四位旧说话人各一句、两房间、请求RT=0/.15/.35、三个方向、两噪声及原场型。每例产生真值参考功率比掩码的MVDR和μ=1 MWF，共864输出。不是新独立验证、部署系统、最优掩码或理论上界。

只把原有 E-to-mask 公式中的E替换为已验证的全混响量化参考语音，不改STFT、协方差归一化、求解器或正则。MVDR仍分别按掩码和归一化；MWF仍共同按帧数归一化，不把它们比较解释成只换求解器。权重使用真值，必须标明不可部署。

预检固定首个源语句、OOFFICE、点源相对−80°、目标20°，覆盖两房间和全部RT，共6条件12输出。验证量化参考恢复、与未改动滤波函数输出逐位相等、分量可加和质量指标。通过后归档，再执行全部条件。无新训练、ASR、超参搜索或下载。

保存功率比掩码及原McNet掩码相对真值协方差的真值能量加权形状误差，形状误差为本项目诊断量，不能等同论文MISD或识别正确率。另保存固定滤波器对语音/有效噪声分量的响应指标。原始McNet与真值协方差波形和成绩直接复用。信号阶段通过后再单独决定识别评分。
