## 1. 修订后的结论：先确证问题，再选择方法，最后逐步扩展实验

当前建议题目：**《基于深度学习的多通道语音增强复现与语音内容保真研究》**。只有诊断实验确认了稳定的误抑制问题、相关方法对比明确了改进空间，才考虑改为带有“空间一致性受限残差恢复”的方法型题目。

建议以 **McNet 官方六通道离线模型为条件主基线**。当前优先任务是验证官方权重、在多段音频上复现并诊断失效，不预先决定训练恢复模块。最多保留 **SpatialNet-small** 一个备用基线。两者都有前置条件：McNet 官方仓库本次未发现明确许可证，必须在后续修改、再发布之前核清授权；SpatialNet 官方 NBSS 实现有 MIT 许可证，但本次未核实可直接使用的官方预训练权重，因此备用路线可能涉及从头训练，不能当作即插即用替换。

当前先回答：**McNet是否在某些明确条件下，跨语句、跨说话人地出现可复核的语音内容损失？其原因是模型抑制、输入不可辨认、识别器偏差，还是预处理错误？** 本次文献调查不能代替这一步实验，现阶段没有证据断言本机McNet存在明显、稳定的人声误删。

只有问题得到确认，才进一步问：已有固定回混、Bridge/BOA式自适应回混或空间后滤波是否已经能解决？如果这些方法已经足够，就没有必要再加模块。恢复模块、损失调整或空间可靠性处理均保留为候选，不提前绑定问题与解法。

已有工作已经包括识别损失、音素损失、冻结模型后的自适应回混、空间相干后滤波和扩散修复。因此不能把“加入 ASR”“增加门控”“回填原始音频”“使用空间信息”直接写为创新。**比原McNet更好仅能证明改动有用，不能证明优于已有方法，更不能单独证明创新。** 后续若主张方法增量，必须选择与机制最接近的已有方法作可核查对照；简化门控与空间破坏只提供内部归因证据，不能替代这一步。

本轮按反馈作了三项修订：增加问题确证门槛；将恢复方案降为条件性备选；把大规模评测拆成“小样本诊断—最小方法验证—按需扩展”。文献与代码核查事实不变，目前仍未进行任何新推理、训练或算法实现。

### 1.2 方法设计前必须通过的问题确证门槛

**第一步：排除复现与评价错误。** 检查通道顺序、参考麦、采样率、归一化、时间对齐、分块边界和目标定义。先在接近原模型设置的条件下诊断；若仅在强混响或错位阵列下失效，应明确限定为域外问题，而非泛称McNet会吞字。

**第二步：预先固定一批多段音频，不只挑失败样本。** 初轮取20—30条不同源语句，覆盖4—6位说话人，每条构造2个条件，共40—60个短混合，在2类噪声、2档SNR间均衡分配，不做完整全因子组合。初期固定一个阵列、一个语言和低/无混响。源语句包含正常语速、弱音、词尾等内容，但不能先看McNet输出再决定是否纳入。另取少量干净/高SNR与纯噪声样本作控制；这是诊断集，不是用于最终宣传成绩的测试集。

**第三步：逐例建立证据。** 对每条记录“目标参考—带噪输入—McNet输出”、词/音素对应时间、可试听片段、统一尺度的谱图和一个固定ASR的结果。删除错误或幅度下降只能标记疑似病例；须核查目标中确有该内容，以及输出中的发音线索是否确实更弱/缺失。只有ASR出错而声音仍保留时，应归类为识别器敏感性；输入本就不可辨时，也不能仅凭输出缺字认定模型新增误删。无法判断的病例单列为“不确定”。研究者试听是诊断核查，不冒称多人主观可懂度实验。

**第四步：用新增语句确认重复性。** 提出具体失效描述后，冻结描述与判定规则，在8—12条新增源语句、每条2个条件（16—24个混合）上检查，不再反复挑样本。建议把“发现批至少3条不同源语句、至少2位说话人出现同类明确问题，并在确认批至少2条新增语句上复现”作为进入方法设计的操作门槛。这不是显著性标准或发生率估计；报告全体样本分母、明确/不确定/无问题的数量，不把同一语句多次混噪当成独立复现。只在某种噪声复现时，题目与结论就限定于该噪声。未复现则继续检查原因或换问题，不硬做恢复模块。

**第五步：按证据选方案。** 优先修复实现错误；若是ASR敏感性，研究识别前端兼容；若是混响/阵列失配，考虑训练覆盖或可靠性；只有确有语音误抑制且观测残差仍包含可恢复线索，才评估第5节候选机制。之后再核查近邻方法、测恢复能力上界，并决定是否训练。

诊断集、确认集一旦用于选问题或选方法，就属于开发证据；后续仍需另留小型锁定测试集，不能把诊断中挑出的失败例充当改进方法的独立泛化证据。

## 2. 问题定义与当前研究水平

### 2.1 先区分四个经常混淆的任务

多麦克风录音可写为：

\[
x_m(t)=(h_m*s)(t)+n_m(t)+\sum_j(h_{m,j}*u_j)(t).
\]

这里，\(s\) 是目标说话人，\(h_m\) 是房间及传播路径，\(n_m\) 是环境噪声，\(u_j\) 是其他说话人。降噪、去混响、多人分离、指定说话人提取是不同任务。单一“PESQ 变高”不能证明这四件事都做好了。

本项目最低版本限定为：**六路同步输入、一个主要目标说话人、输出参考麦克风对应的一路增强语音；首先研究降噪，混响作为失配因素分层评测。** 不同时承诺多人分离、移动声源跟踪、实时会议系统和助听器部署。双人重叠仅作为后续压力测试；没有方向或身份条件时，系统可能根本不知道哪一个人是目标。

必须先定义目标信号：

- 仅降噪：目标为参考通道的混响语音 \(s_r=h_r*s\)。
- 联合去混响：可选择直达声或包含固定早期反射窗的语音，但训练、验证和所有指标必须统一。
- 不可用干净无混响源评判一个只承诺降噪的模型，再把全部混响误差解释成“吞字”。也不可把去除混响尾巴直接算成词尾丢失。

### 2.2 主流技术路线

| 路线 | 代表与机制 | 成熟部分 | 本课题仍需面对的问题 |
|---|---|---|---|
| 神经掩码 + MVDR/多通道维纳滤波 | 网络估计语音/噪声，再估空间协方差和线性滤波器 | 空间滤波、阵列处理、与 ASR 结合已有长期积累 | 掩码错误、低信噪比、协方差病态、运动源导致失真或漏噪；“无失真”仅在模型与约束成立时成立 |
| 时域滤波/分离 | FaSNet、FaSNet-TAC 等 | 可学习滤波、通道聚合与变通道输入已有先例 | 阵列泛化、计算预算、语音细节损失仍需验证 |
| 复数 STFT 映射 | McNet、SpatialNet、TF-GridNet | 沿时间、频率和空间维度建模非常成熟；可处理幅度与相位 | 固定阵列依赖、长序列显存、域外噪声；回归目标不直接等价于内容保真 |
| Mel 特征增强 + 声码器 | Mel-McNet | 压缩表示、增强与生成解码结合，可降低部分计算量 | 细节来自输入还是声码器先验更难区分；自然度与逐字忠实度可能冲突 |
| 扩散/生成式修复 | UNIVERSE++、ArrayDPS-Refine、Uni-ArrayDPS | 生成式语音先验、后级修复已经有人研究 | 多步推理、预训练成本、音素替换或生成伪影；不适合作为本项目首选训练主线 |
| ASR/音素/自监督约束 | 冻结识别器特征损失、CTC、音素表征匹配 | 均有正式先例，且已有多通道工作 | 对教师模型过拟合、语言迁移、显存、ASR 与人耳目标不一致 |

McNet 将不同类型的空间与谱信息分阶段建模；SpatialNet 交替使用窄带和跨带模块；TF-GridNet 将时频域建模与多通道滤波结合。这些结果说明应复用成熟主体，研究小而明确的改动，而非从零重写“大模型”。论文之间训练数据、目标信号、声道数和离线/流式条件不同，不能直接按表中最好数字排列为统一冠军。[R1–R5]

2023—2026 年的重点逐渐扩展到：流式处理和效率、阵列与真实房间泛化、生成式后处理、识别与听感的共同评价。2026 年 ArrayDPS-Refine 已提出用干净语音扩散先验修复判别式多通道模型；其扩展 Uni-ArrayDPS 在所查页面仍标为在投。说明“后处理修复失真”已有明确竞争工作。[R15–R16]

### 2.3 为什么会吞字，为什么“留更多能量”也不一定正确

1. 擦音、塞音释放和词尾能量弱，短时频谱可能与风声、刹车、键盘等噪声相似；模型可能宁可抹去，也不冒保留噪声的风险。
2. 回归损失容易被高能量元音主导；很短的辅音错误可能几乎不影响整句平均分。
3. 混响会扩散时间结构和空间特征；实际麦克风位置、增益、同步误差与训练不同会破坏空间判断。
4. 生成式模型可能输出“像语音”的内容，但这不保证是原句。语义相近也不能代替逐字准确，例如数字、专名、否定词和词尾变化。
5. ASR 有自己的语言模型偏置。WER 降低不等于人类更易听懂；对一个 ASR 有效，也未必对另一个有效。
6. 将原始音频加回来会同时恢复语音和噪声；相干性高的信号也可能是定向噪声或其他人，不能将“相干”直接等同于“目标语音”。

伪影对识别和人耳的影响已有实验研究；PESQ 优化和可懂度代理指标也有反例。本文因而采用“质量、内容、误回填”三组证据，而非只报单个指标。[R6–R14]

### 2.4 典型训练方法与“保护内容”的不同层次

以下是代表性论文中反复出现的训练方式，不是对整个领域使用比例的统计排名：

| 训练方式 | 信号与监督 | 对内容保护的作用 | 代价或边界 |
|---|---|---|---|
| 配对监督与动态混噪 | 干净语音、多通道传播与噪声，随机SNR、房间和位置 | 提供可控目标与足够干扰覆盖 | 模拟器的空间分布不真实会形成域差；同一语句多次混合不等于增加独立说话人 |
| 波形/复谱/掩码重建损失 | SI-SDR、复数谱误差、压缩掩码误差、多分辨率STFT等 | 约束声音与目标匹配，容易训练和复现 | 各自具有尺度、能量权重或表示偏置；McNet原配方是压缩cIRM误差，不能笼统写成全部用SI-SDR |
| 感知/对抗训练 | 质量代理分数、判别器或感知表征 | 改善某些自然度、质量和频谱表现 | 可能利用评价器漏洞，或使声音自然却不忠实；需要独立评价 [R11、R14] |
| ASR任务监督 | 人工转写的CTC/序列目标，或冻结识别器表征 | 直接约束机器识别可用的信息 | 冻结教师不等于零显存；不可将不可微WER直接当普通反传损失 |
| 音素/自监督表征约束 | 音素边界、教师编码器中间层、增强/目标特征匹配 | 关注短时发音结构，减少仅靠整句幅度的盲点 | 中间表征不都是音素，也不一定对数字/词尾变化敏感；需跨模型验证 [R11–R13、R17] |
| 课程式或分阶段适配 | 先训练主体，再冻结/局部微调；从短片段开始 | 降低有限GPU下的优化与资源风险 | 改变训练预算后不能声称严格复现原论文；短片段可能缺少空间统计或词语上下文 |

训练常使用随机片段、小批量与自适应梯度优化；本项目应沿用所选官方基线的已验证配置，而非同时更改优化器、损失和架构。论文中的“音素损失”有时是ASR编码器特征差异，并非显式逐音素标签；“语义一致”也不等于原始发音完整，不能混用这些术语。

**McNet 已核实的关键细节。** [offline 配置](https://github.com/Audio-WestlakeU/McNet/blob/main/config/mc_net_offline.yaml) 选取 `[0,1,2,3,4,5]`，`ref_channel=4` 为第5支麦克风；STFT 512/hop256，训练片段3.072秒，输入实虚拼接12维。原目标是压缩 cIRM 的实虚 MSE，不能误写成直接波形 MSE。[核心代码](https://github.com/Audio-WestlakeU/McNet/blob/main/src/model/mc_net.py) 的 `cIRMIO.prepare_time_domain` 从 cIRM 恢复复谱再做 iSTFT，拟议模块应接在恢复后的复谱处，不能直接把压缩 cIRM 当幅度增益。

权重文件：[offline](https://github.com/Audio-WestlakeU/McNet/blob/main/model_checkpoints/offline/epoch494_criteria18.78_sdr18.78.ckpt) 39,999,375 bytes；[online](https://github.com/Audio-WestlakeU/McNet/blob/main/model_checkpoints/online/epoch454_criteria18.35_sdr18.35.ckpt) 22,191,935 bytes。字节数只证明文件条目存在，不证明模型可用，也不等于参数量。旧代码包含 `trainer.gpus`、`test_epoch_end` 等接口，[requirements](https://github.com/Audio-WestlakeU/McNet/blob/main/requirements.txt) 的宽松版本约束不足以保证 Python 3.12 兼容。

**SpatialNet 的结构支持与模型可用性必须分开。** [配置](https://github.com/Audio-WestlakeU/NBSS/blob/main/configs/SpatialNet.yaml) 和 README 支持六通道 `dim_input=12`；双说话人输出4维与单目标输出2维不能混用。原默认8kHz配置与16kHz配置的频点数不同，不能直接换采样率而假定权重兼容。论文表XI在六通道、4秒、双说话人口径下报告16k small约1.6M参数/46.3 GFLOPs每秒音频，large约7.3M/237.9；这些不是显存数据。长时注意力的激活可能比参数更占显存。

[RealMAN 的 SE baseline](https://github.com/Audio-WestlakeU/RealMAN/tree/main/baselines/SE) 也没有解决权重缺口：所查 README 仍为 checkpoint 占位路径；SpatialNetTiny 配置默认9通道，不是现成六通道权重。RealMAN README 的 CC-BY-4.0 明确针对数据，不应自动推广为所有 baseline 代码的许可。

**Mel-McNet 有权重，但增加了重建变量。** 已查到[增强 checkpoint](https://github.com/Audio-WestlakeU/Mel-McNet/blob/main/logs/McNet_separation/checkpoints/epoch32_metric0.0202_final.ckpt) 77,459,189 bytes，以及[对应配置](https://github.com/Audio-WestlakeU/Mel-McNet/blob/main/logs/McNet_separation/mel-mcnet-final.yaml)。作者 [HF 文件列表](https://huggingface.co/EvanYYJ/Mel-McNet/tree/main) 包含 Vocos 和 E-branchformer。Vocos 用于波形重建，E-branchformer 用于作者识别评价，不是所有推理都必须加载 ASR。配置使用四卡训练、作者绝对路径，且固定 Torch 2.1/CUDA12.1 相关依赖，不能直接照搬到当前 Python3.12。

Mel-McNet 原论文表1中，其与同文重训 McNet 的 WER 相当，但经 Vocos 的 PESQ/STOI 较低。这里作者的 ASR 可以直接使用增强 LogMel，而波形指标经过声码器；本项目若做波形 WER，必须给各系统使用同一个波形 ASR，不能照搬论文中的数值比较。声码器影响应与增强骨干影响分开。[R3]

**TF-GridNet 权重不匹配的具体证据。** 作者贡献的 [ESPnet 实现](https://github.com/espnet/espnet/blob/master/espnet2/enh/separator/tfgridnet_separator.py) 可设置 `n_imics`，但[核实的作者归档](https://zenodo.org/records/7565926) 是8kHz、单麦、双说话人分离模型。代码可配置六通道不等于这份权重能够六通道增强。LABNet 的[配置](https://github.com/Jokejiangv/LABNet/blob/main/config.yaml) 是本地 checkpoint 路径，其 `num_channels` 也不能未经语义检查就理解为麦克风数。

### 3.3 基线选择规则

首先检查官方实现、授权和可获得的权重，再考虑原生六通道、资源成本、可修改性与论文价值。这里不做主观数字打分，以免掩盖“无权重”和“无明确许可”这样的硬约束。

**主基线：McNet 官方 offline 六通道 checkpoint，条件推荐。** 优势是有仓库内权重、原生六通道配置、输出仍可在 STFT/波形域分析，适合冻结主体后比较细节恢复。前置条件是代码及权重许可明确、旧依赖兼容、checkpoint 与配置匹配，以及短句推理显存通过。没有这些验证之前，不称为已经复现成功。

**备用：SpatialNet-small 的 MIT 官方 NBSS 实现，条件推荐。** 窄带/跨带结构更系统，论文涉及噪声、混响和分离，适合空间问题研究。但本次未核实已发布的可用官方 checkpoint；其阵列相关性意味着改输入维度不足以获得六通道性能。仅在取得适配权重，或明确接受预算内小规模重新训练后启用。

Mel-McNet 是有价值的对照文献，但本项目不将其列作第二备用：声码器依赖与重建机制会增加“细节究竟从何而来”的归因难度；同时仍有许可待核查。TF-GridNet 等保留为背景与可选外部参照，不增加并行复现任务。

**停止门槛：** 如果主基线授权或加载失败，备用又没有可接受的权重/训练预算，应报告路线受阻并重新选型。不能为了赶进度悄悄改用第三方不明权重或声称已经满足复现条件。

## 4. 五个候选方向：已有先例、具体增量与实验判据

所有方向均是研究假设。估计训练成本不包括下载和配置耗时，也不承诺若干小时必然完成。

### 方向 A：空间证据约束的残差恢复（问题确证后再考虑）

**已有成果。** OA 将观测信号加回增强结果；Bridge 学习回混系数；BOA 已学习时频相关系数；双通道相干后滤波也存在。冻结主体、时频门控、空间相干都不能单独主张新颖。[R6–R10、R18]

**具体不足与待检验问题。** 仅依据增强结果与单路输入，难区分“被错删的辅音”和“正确删掉的噪声”。已有空间后滤波并不自动回答：在冻结的现代六通道模型上，空间信息是否能减少内容恢复时的错误回填。

**可实现增量。** 在基线复数输出后、iSTFT 前，插入小门控。输入包括参考通道与输出的谱差、若干通道对 IPD 的正余弦、短时相干、相对于估计目标空间模式的匹配程度。只恢复现有观测残差的一部分；加入恢复幅度约束和无语音段惩罚。第一版恢复来源固定为参考通道，后续再比较空间滤波分支，避免同时改两个因素。

**训练与成本。** 若问题确证和近邻对照支持该方向，可冻结 McNet，缓存其输出，只训练约5万—30万参数的门控（设计预算，非已确定结构）。首个学习实验先用约0.5—1小时独立训练源语音，单次训练检查趋势；有收益才扩到2—5小时。早期诊断不训练。8GB下短片段、小batch训练小模块预计可行，但完整长句推理和实际训练显存均须实测。

**如何证明。** 问题确认后，先比较固定回混、一个最接近的已有方法与候选模块；声称空间贡献时补同容量无空间门控。空间破坏、恢复惩罚和未见噪声类型留作针对性扩展，不一次全部展开。看删除率、CER/WER与质量/漏噪权衡；若优势仅来自更大模型或回填更多噪声，就不支持假设。

**重复风险、难点与本科成果。** 与 BOA/相干后滤波高度邻近，创新强度谨慎评为“小幅方法改进或系统实验贡献”。低 SNR 时目标空间模式难估计，门控也可能锁死原模型错误。即使失败，严格证明空间信息在特定失配下无益、找出失败边界，也可形成有质量的本科论文。

### 方向 B：弱语音与词尾的非对称保护损失

**已有成果。** 频率加权 SDR、音素级分析和目标说话人音素损失已有多通道先例，不能把“给辅音更大权重”直接当新方法。[R11–R13]

**不足。** 固定高频权重会把高频噪声一并放大；音素边界和低能量帧也不完全重合，持续的低能量背景不能当语音保护对象。

**具体改进与位置。** 在损失端增加有限幅度的非对称项：仅对训练真值中确认有语音、且属于低能量或已对齐辅音的区域，更强地惩罚低估；对噪声独占帧保留输出能量惩罚。先用确定的能量分位与短时变化标注，再把人工校验的音素边界作为扩展，不让推理依赖真值。对比同样权重但对称损失，以及已有频率加权损失。

**训练、8GB 与成本。** 损失本身开销小；若微调全模型，显存取决于 McNet 反向传播，而非损失大小。优先只微调输出层或用于方向 A 的门控；全量微调 1—2 秒片段、batch 1 仅属待测方案。重训基础模型不是最低版本要求。

**证据。** 报告辅音/词尾区域缺失率、整句指标、无语音段漏噪和不同噪声类别的权衡。不要只展示权重正好优化的指标。

**重复、风险、成果。** 与 MMSP 2025 工作很近，创新较弱；可作为可靠消融或候选改进。边界标注错误、音量归一化偏置、中文与英文音素定义不同都可能产生伪增益。适合形成“小改动 + 细致局部诊断”的本科成果。

### 方向 C：冻结语音表征教师的内容一致性微调

**已有成果。** ASR 联合训练、音素表征损失、UNIVERSE++ 的音素保真微调，以及多通道方向增强中的 ASR 编码器约束都已存在。[R11–R12、R17]

**具体不足。** 一个教师模型的偏差可能被当作内容真值；语义特征可能不敏感于漏掉一个否定词；对教师的识别提升可能无法迁移。

**具体改进与位置。** 在增强输出后接一个冻结的较小语音编码器作为训练期教师，比较增强与干净目标的中间层帧级表征，搭配原始重建损失；只更新输出适配层。真值教师特征可离线缓存，但增强分支仍须保留对输入的梯度，不能用 `no_grad` 断开。CTC 若加入，应使用人工/数据集转写，并设置独立对照；不对 ASR 生成文本直接“反传 WER”。

**训练与资源。** 需要微调；教师冻结仍占激活与输入梯度显存。8GB 上较小教师、短片段、顺序运行有机会，增强与大 ASR 同时全量训练不推荐。估算成本明显高于 A/B，具体峰值未验证。

**证据。** 若最终选择这一较高成本方向，尤其需要区分训练教师与独立识别器，检查是否只对教师有效；逐字错误及数字、专名、否定词可作切片。先做重建损失与教师损失的最小对照，有趋势再补普通log-Mel与独立ASR。未做独立验证时不声称跨教师泛化。该方向暂不纳入当前最低执行计划。

**重复、风险、成果。** 直接采用教师损失重复性高；若能证实低资源下跨教师泛化和特定内容片段保护，才有增量。最大风险是“为某个识别器优化”并牺牲音质。本科可完成适配层实验，不宜把训练完整识别器作为主线。

### 方向 D：麦克风失配下的空间可靠性估计

**已有成果。** FaSNet-TAC、USES 系列、RealMAN 的变阵列研究已经处理通道数量和阵列泛化；随机丢通道不是新点。[R5、R19、R34–R35]

**具体不足。** 变通道支持不代表对坏麦、增益偏差、时间不同步和遮挡都稳健。一个错误空间线索可能恰好导致短辅音被当成噪声。

**具体改进与位置。** 在空间特征输入或方向 A 的门控前，估计各通道对可靠性，用互谱稳定性、异常电平和延迟一致性降低坏通道权重。采用可控的增益误差、固定/缓变延迟、带宽受限和单通道中断训练；不简单把所有通道交换后仍当作同一固定阵列。

**训练与资源。** 只训练可靠性/聚合模块或门控可控制成本；改原模型第一层则需重新适配权重，不能直接沿用六通道 checkpoint 宣称公平。8GB 下小模块方案预计可行，全模型训练仍未验证。

**证据。** 预注册单一和组合失配强度，比较正常阵列、坏麦、普通 channel dropout、可靠性加权；单独测正常阵列是否退化，避免只提高破坏场景指标。

**重复、风险、成果。** 阵列鲁棒已有大量工作，创新点只能落在具体故障识别与内容损失的关联。延迟纠正会误判真实到达时差，数据模拟也可能不现实。适合作为工程应用导向的本科方向，但若与 A 同时完整展开，范围容易过大。

### 方向 E：有约束的噪声抑制—内容保真工作点选择

**已有成果。** OA、BOA、桥接模块、语音失真加权滤波已研究权衡；“调一个降噪强度参数”本身研究价值有限。[R6–R10]

**具体改进与位置。** 在输出阶段保留一个全局保真参数，验证集上选择满足删除率/安静语音退化约束的工作点，而非一味最大化 PESQ。训练一个条件门控或只扫描方向 A 的恢复上限，画出质量—识别—噪声泄漏的 Pareto 曲线。

**训练与资源。** 固定回混扫描无需训练，条件门控仅需小规模训练；8GB 可顺序推理，但不是本机已验证。它是 A 失败时最稳妥的最低交付路线。

**证据。** 同时报告多个工作点；测试集只评估验证集锁定的参数，不逐句用测试 WER 选最优输出。必须包含干净/高 SNR 语音，统计被增强损害的比例。

**重复、风险、成果。** 新颖性低于 A，容易变成调参。若形成跨噪声、跨 ASR 的可靠边界与非劣约束分析，可作为实验方法和系统设计成果，不主张新网络架构。

### 4.1 候选比较与取舍

| 方向 | 额外训练负担（估算） | 对 8GB 友好程度 | 与现有方法重复风险 | 可解释性 | 建议 |
|---|---|---|---|---|---|
| A 空间约束残差恢复 | 低：缓存主体，仅训练门控 | 较高，待短句测量 | 高，须与已有近邻方法比较 | 高 | 仅在误抑制及可恢复性确证后考虑 |
| B 非对称细节保护损失 | 小头低，全模型中高 | 视更新参数范围 | 很高，已有频率/音素损失 | 高 | 一个辅助消融，不独立堆叠 |
| C 教师内容一致性 | 中高 | 有条件，教师激活显存明显 | 高 | 中 | 理想版本扩展，非必做 |
| D 空间可靠性 | 小模块低，全模型中高 | 有条件 | 高，阵列鲁棒非新题 | 高 | 做压力测试；不另起完整模型 |
| E 工作点约束 | 无或低 | 较高 | 很高 | 高 | 最低交付与失败回退 |

不同时实现五个方向，当前也不提前确定A。先根据诊断选一个主要问题，再从候选中选一个最小方法。若证据最终支持A，B/E可作必要对照，D仅用于少量针对性压力样本，C保留为后期扩展。

### 4.2 创新性需要跨过“已有方法对照”，而非只跨过原模型

现阶段创新性评估为**未确定**。后续在选择具体方法前，建立“近邻论文—机制—训练监督—可用实现—拟议差异—对照方式”清单，优先检查R8、R9、R18及与最终失效模式直接相关的论文，而不是只比较更老或更弱的增强骨干。

| 已有方法/对照 | 在本项目中的作用 | 何种结论不能由它单独得出 |
|---|---|---|
| 固定OA/回混（R6等） | 排除单纯减弱降噪就能解决的问题；在验证集选合理参数 | 胜过固定系数，不代表胜过学习型回混 |
| Bridge（R8） | 无需ASR训练的轻量回混近邻，适合优先核查其训练目标、输入和系数估计 | 自己写一个普通小门控不等于忠实复现Bridge |
| BOA（R9） | 时频自适应回混近邻；需核对冻结SE/ASR、特征与ASR监督 | 去掉ASR监督或换McNet内部特征后，应称“BOA式适配”，不能冒称原BOA成绩 |
| 相干/统计空间后滤波（R18） | 检查收益是否已经可由已有空间处理解释 | 原文双通道/不同滤波器下的结果，不能直接与六通道自定义数据数字相减 |
| 同容量无空间门控、空间破坏 | 控制参数量、训练机会和空间信息的贡献 | 属于内部消融，不能代替与已有方法的外部比较 |

**最低方法型证据要求：** 原McNet + 固定回混 + 至少一个机制最接近、能核查实现的已有方法 + 拟议方法。若声称空间机制有独立优势，还应有同容量无空间对照，并核查是否需要增加一个适配的空间后滤波对照。选择一个最相关近邻即可先做，不要求第一轮复现全部论文。

优先采用许可允许的官方实现；若无官方实现，后续可依据论文复现，但必须记录公式、监督、输入、超参数、适配差异及核对程度。能否做到尚待验证，本轮未实现任何对照。区分两种比较口径：同McNet、同数据的机制适配比较有利于归因；原论文完整系统的复现反映其原任务表现。二者不可混作“严格复现并全面超过原方法”。若BOA需额外ASR监督，应披露额外数据/算力，同时保留一个预算匹配的近邻，不人为削弱它后宣布领先。

只有在独立小测试集上，拟议方法相对选定近邻体现出明确的质量—内容—漏噪权衡优势，才继续扩大实验。即便如此，也只能主张**在所测条件下相对已对照方法的增量**；若未超过近邻、或只能实现简化对照，就保留为工程评估/复现分析，不将其包装为已确认的新算法。

## 5. 条件性备选方案：空间一致性约束下的受限残差恢复

**本节保留技术推演，供后续证据支持时使用，不代表已选定的方法。** 启用条件依次为：第1.2节确认真实且重复的误抑制；已有简单/近邻方法不足；残差信号存在可利用的恢复能力。任何条件不成立，都应停用或改选，而不是继续按本节训练。

### 5.1 具体研究问题与可证伪假设

**实际应用。** 面向笔记本/会议设备的远场录音清理：希望降低键盘、风扇、道路等背景声，同时减少对弱辅音、短词和词尾的损害。最低版本是离线处理和实验验证，不承诺实时产品。

**条件主假设 H1：** 在误抑制确已存在的条件下，加入真实跨通道空间特征，可在同容量、同训练机会下优于仅依据单路谱差的门控；进一步与第4.2节选定的已有近邻比较，检验这种差异是否具有实际增量。第一项是归因证据，第二项才涉及方法价值。

**辅助假设 H2：** 恢复上限与噪声独占帧惩罚，可以避免通过大量回混原声换取表面上的删除率下降。

**边界假设 H3：** 上述优势可能在强混响、近同方向干扰、错误同步或极低 SNR 时消失。测出这一边界是研究内容，不将所有失配一律解释为实现问题。

否证或收缩结论的条件包括：未确认稳定误抑制；空间门控不优于同容量无空间门控；不能优于选定已有近邻；打乱空间线索仍维持同样收益；与固定回混在相同噪声残留下无差别；后续独立ASR/听写不支持早期结果。早期尚未做独立ASR或听测时，只能报告单识别器/信号级观察，不能提前声称跨识别器或主观可懂度改善。

### 5.2 模块位置与信号流

```text
六路同步波形 → 官方 STFT/归一化 → 冻结 McNet → 解压 cIRM → 增强复谱 Y
       │                                                   │
       ├→ 参考通道复谱 Xr → 候选残差 D = Xr − Y             │
       └→ 通道对相位/平滑相干/目标模式匹配 → 小门控 g        │
                                                           ↓
                              Z = Y + g·D → 官方匹配 iSTFT → 一路波形
```

第一版取恢复来源 \(B=X_r\)，固定为原参考通道，并使用同一 STFT、参考通道、尺度和时间对齐。记 \(D=B-Y\)，输出为：

\[
Z_{t,f}=Y_{t,f}+g_{t,f}D_{t,f},\qquad
0\leq g_{t,f}\leq g_{\max}\leq1.
\]

\(g=0\) 保持基线结果，\(g=1\) 回到参考观测；中间值沿观测残差方向恢复，不凭空合成一段语音。因此该参数化表达能力有限：若原观测已经没有可用内容，或相位关系不允许修复，它无法“补出正确字”。这正好使错误来源更可解释。

**可选扩展，而非第一版必做：** 用对齐到参考通道的保守 MVDR 输出作为 \(B\)，减少直接回混噪声。必须与同一个门控及同一损失交叉比较，不能把更好的波束形成分支收益全算到空间门控。若基线目标为去混响后的直达声，原混响观测不再是同一种目标，必须先解决目标一致性，或将研究限定为降噪；不能随意把混响尾巴加回去。

### 5.3 空间证据具体如何计算和使用

相对参考麦克风的 IPD 使用 \(\cos\Delta\phi\)、\(\sin\Delta\phi\) 编码，避免相位在 \(-\pi/\pi\) 处不连续。先固定通道对选择，记录它们与阵列几何的对应关系。不能把通道序号错位的输入当作正常空间特征。

相干性必须由一段时间的互谱与自谱估计，而不是用单个时频点直接归一化：

\[
\gamma^2_{mr}(t,f)=
\frac{|\operatorname{EMA}(X_mX_r^*)|^2}
{\operatorname{EMA}(|X_m|^2)\operatorname{EMA}(|X_r|^2)+\epsilon}.
\]

逐点计算 \(|X_mX_r^*|^2/(|X_m|^2|X_r|^2)\) 会几乎恒等于1，没有判别意义。平滑时间常数只在验证集选择，强非平稳噪声下过长平滑也会失效。

门控的候选输入分为三组：

| 证据 | 示例 | 用途与限制 |
|---|---|---|
| 谱差与短时动态 | \(\log(|B|+\epsilon)-\log(|Y|+\epsilon)\)、输出/输入比例、时间差分 | 提示可能过抑制，但大差值也可能表示正常降噪 |
| 跨通道空间特征 | IPD、平滑相干、通道对一致性 | 辅助区分空间模式；定向噪声同样可能高相干 |
| 目标空间模式匹配 | 从高可信语音帧估计相对传递模式，衡量当前残差是否匹配 | 不使用测试真值位置；高可信帧估错或移动声源会污染模式 |

若候选A被选中，首个方法实验可先不加入目标模式匹配，只检验简单IPD/相干的独立价值；再加模式估计时须增加单独消融。普通“高相干就回填”不足以作为完整方法。针对相干机制，先选一种与诊断相关的定向噪声作少量难例；近同向干扰和强混响按需追加，未覆盖时明确限制，不能声称对这些条件也稳健。

门控可采用少量频带的局部卷积/小型时序网络，输出有界系数，频率插值到原 STFT。具体层数、频带数、上下文长度留给后续预算测试；本轮不编造已确定的最优配置。离线主基线使用未来信息，因此整个系统应标为离线；即便门控本身因果，也不能称全链路实时。

### 5.4 先测恢复上界，再决定是否值得训练

在有干净目标 \(S\) 的验证混合上，可计算受同样约束的理想门控：

\[
g^*_{t,f}=\operatorname{clip}\left(
\frac{\Re\{(S-Y)D^*\}}{|D|^2+\epsilon},0,g_{\max}\right).
\]

它是沿候选残差方向减小复谱平方误差的参考上界，**只用于训练标签或机制分析，不是对 WER、PESQ 或听感的理论上界**。不能在测试系统中输入真值来预测门控。

若连理想门控都无法改善目标弱语音切片，说明恢复来源或参数化没有可用信息，应停止该机制，改选问题或转向方向 E；不必盲目增加网络。若理想门控有效而学习门控无效，则问题在可观测特征、监督和泛化，而非“没有更多训练轮数”。

### 5.5 训练目标与约束

第一版仅使用可解释的信号级训练，不引入大 ASR 反传。建议从以下组合逐项验证：

\[
\mathcal L=
\mathcal L_{\mathrm{rec}}(Z,S)
+\lambda_g\|g-g^*\|_1
+\lambda_n\mathcal L_{\mathrm{noise-only}}
+\lambda_s\mathcal L_{\mathrm{smooth}}.
\]

- \(\mathcal L_{\mathrm{rec}}\)：波形/复谱或多分辨率 STFT 重建项；先选择一种稳定基准，再加其他项。
- 门控监督是可选项；理想系数在残差很小时不稳定，应屏蔽低残差点或按其能量加权，避免监督无意义的大系数。
- 噪声独占帧惩罚：由训练混合的真实语音活动定义，约束无语音时的输出能量和恢复量，防止网络变成持续漏噪器。测试不能用真实语音活动控制门控。
- 平滑项避免剧烈跳变，但不能过度抹去塞音；需比较有无平滑，不能以“更平滑”替代内容保真。

非对称细节保护项是方向 B 的辅助实验，应明确引用已有 TSOS/非对称损失研究，不单列为独立创新。所有超参数以验证集锁定；最终使用哪个组合取决于消融，不预先保证所有项都有效。

### 6.2 模拟六通道必须保证空间一致

干净语音与噪声均应依据同一个房间和麦克风几何生成。对各麦克风使用同一源、不同RIR形成传播时差与混响；噪声采用多个不同位置点源、适当的扩散场模拟，或与阵列几何一致的真实多通道噪声。不能给每个麦随意混入独立噪声就声称是真实空间噪声；也不能仅增加时延便声称覆盖混响。

最低版本先使用与基线尽量一致的固定阵列、静止目标、正确同步和可复现随机种子。RIR 生成工具、声速、坐标、参考麦、SNR 定义与测量语音活动规则都必须记录。SNR 建议在参考通道的语音活动区间定义；同一混合中所有系统使用完全相同的缩放，不给不同系统单独调音量。

原 McNet 仿真主要无混响，故先建立无混响/低混响的匹配条件。加入中强混响是域外研究，不应把“原模型没学过混响”误判为新模块的创新证明。比较新模块时必须给无空间门控相同的混响训练机会。

### 6.3 缩小后的分阶段数据规模（拟定，不是已生成）

**规模按证据逐级扩大，不把最大版本当起步要求。** 同一源语音的多个混合算多个条件，不算多个独立内容样本；各阶段开发数据与最终测试分开。

| 阶段 | 数据与条件 | 训练、识别与评价 | 暂不做 |
|---|---|---|---|
| 首轮诊断 | 20—30条源语句、4—6位说话人，每句2个条件，共40—60个混合；2类噪声、2档SNR均衡分配，固定阵列、低/无混响 | 官方McNet推理；1个固定ASR；SI-SDR/PESQ/STOI、编辑错误与研究者逐例核查 | 新模块训练、多个ASR、真实数据集、大批消融、多人听测 |
| 问题确认 | 8—12条新增源语句，每句2个条件，共16—24个混合 | 冻结失效描述和判定规则，只确认重复性 | 扩大噪声/房间组合来寻找更容易展示的失败例 |
| 最小方法验证 | 只有问题确认后才取约0.5—1小时训练源语音；另取10—20条验证源语句；锁定约30—50条全新测试源语句，每句约4个均衡条件，共120—200个测试混合 | 一种候选方法、一个最接近已有方法、必要简单对照；先各1次训练，1个ASR | 一次实现五个方向或全量重训主体 |
| 按需扩展 | 有稳定趋势后，一次增加一个因素：约20—40个新噪声/混响样本，或20—50句真实录音；训练源语音按需扩至2—5小时 | 优先补最影响结论的一项：重复训练、独立ASR、真实场景或空间破坏 | 自动做所有扩展；未经审核恢复原600混合与多套大规模计划 |

初轮可选0与5dB两档SNR，包含一类相对稳定噪声和一类非平稳噪声；具体类别按可获得且许可清楚的数据选定，执行前固定。该设置是探索起点，不预设这些条件必然造成吞字。先完成与训练条件较匹配的验证，再根据诊断决定是否加入-5dB或混响。不同房间、4类噪声、5档SNR等完整矩阵不再列为最低要求。

最小方法阶段如果只使用原两类噪声，只能主张在该范围内、未见语句/录音上的效果。若要主张对未见噪声类型泛化，再另加一类完全留出的噪声；不能把同类型新片段称为未见类型。最终测试集不能按诊断失败例筛选，应包括正常和失败条件，报告总体及预定义切片结果。

若问题集中于某一种失配，扩展只验证它及一个邻近对照，例如额外一档混响或一个坏麦条件；不同时做目标移动、阵列几何、双人重叠与中英迁移。真实中文与几何同时变化时，明确其混合域差，不强行归因。

另取少量干净/高SNR语音和纯噪声输入作控制。纯噪声不能计算有意义的语音SI-SDR/WER分母，使用输出能量与ASR误触发作诊断。这些控制样本不需要扩成一套大数据集。

### 6.4 防止实验数据泄漏

1. 按**说话人、源语句、原始噪声长录音、房间/RIR和真实场景**分组划分；同一语句换SNR不能跨训练/测试，同一噪声长录音切两段也不视为完全独立。
2. 保存样本清单、原始文件哈希、混合种子、说话人ID、噪声录音ID、房间ID、通道映射和参考定义。归一化统计与阈值只能由训练/验证确定。
3. 检查官方checkpoint训练来源与拟定测试数据重叠。已预训练权重无法追溯全部来源时，标注“预训练数据重叠未完全排除”，增加明确未见的噪声/场景验证；不能仅保证门控数据独立就宣称全链路零泄漏。
4. 训练使用的音素对齐、干净参考和转写不进入推理输入。测试真值只用于评分和预先定义的离线诊断。
5. 测试集不用于挑选回混系数、选择哪个ASR、决定停止轮次或筛选好听样本。案例按固定规则同时抽取成功、失败和随机样本。
6. 若两种ASR都参与多次选模，它们都不再是独立评估器；至少保留一个不参与训练和模型选择的识别器用于锁定后的最终比较。

## 7. 实验指标：质量、内容与错误机制分开证明

### 7.1 指标含义与不能支持的结论

| 指标 | 衡量什么 | 使用条件与报告方式 | 不能直接证明什么 |
|---|---|---|---|
| SI-SDR / SI-SDR improvement | 去除全局尺度后的波形目标匹配，兼含残余噪声与失真 | 同一目标参考、同一对齐；报dB和相对带噪输入变化；纯静音另行处理 [R22] | 不识别词/音素；整句高分不代表辅音未丢失；尺度不敏感会掩盖音量问题 |
| PESQ-WB | 与参考相比的语音质量代理 | 16k宽带、固定实现/模式；有合法且合适的干净参考才计算 [R24] | 不等于逐字保真、主观可懂度或ASR正确率；不把窄带/宽带分混报 |
| STOI / 可选ESTOI | 短时频带包络与参考的相关性，可懂度代理 | 固定实现、整体及分层报告 [R23] | 不直接判断某个词被删除，也不代替真实听写 [R21] |
| WER / CER | 固定识别器相对于人工转写的词/字编辑错误 | 英语优先WER、中文优先CER；固定分词、大小写、数字及标点处理 | 是机器任务指标，不等于人类可懂度；语言模型可猜对缺失声音 |
| 删除/替换/插入率 | 识别错误的类型 | 分别报D/N、S/N、I/N，并与输入/基线配对 | 删除错误不完全等同声学吞字；词尾变化也可能被计作替换 |
| TSOS与局部欠估计统计 | 对有参考语音的过抑制时段作诊断 | 复用已有定义或清楚标为项目自定义；报告持续时间和阈值敏感性 [R17] | 非通用内容指标；噪声泄漏会掩盖能量丢失，不能据此单独证明恢复正确 |
| DNSMOS（可选） | 无参考的质量预测 | 真实数据补充，记录预测模型版本；不可直接等同人工MOS | 不能验证原话内容；同一预测器上升也可能是偏置 |
| RTF、峰值显存、吞吐 | 工程可用性 | 固定音频长度、精度、设备；分模型/全链路，含STFT/iSTFT | 离线RTF<1不代表流式低延迟，FLOPs也不等于显存 |

SI-SDR 可写为：\(s_{\rm target}=\langle\hat s,s\rangle s/\|s\|^2\)，再计算目标与误差能量比。必须区分它与允许较长滤波拟合的旧 BSS-eval SDR，不将两种定义的结果混用。[R22]

\(\mathrm{WER}=(S+D+I)/N\)，CER将计数单位换为字符；WER可能超过100%。同时报告语料级总编辑数/总字词数，以及句级增减分布，不把长短句简单平均后的比率冒充语料WER。\(\Delta\mathrm{WER}=\mathrm{WER}_{\rm processed}-\mathrm{WER}_{\rm noisy}\)，负值才表示改善。

初轮只使用**一个固定ASR**，比较干净目标、带噪参考、McNet三路；有改进方法后再增加其输出与已有近邻。干净目标的识别错误揭示识别器自身问题，不要求其为0。独立的第二个ASR属于后续验证评价器依赖的扩展，未做时不主张跨识别器泛化。具体模型及许可证在执行阶段另核查，不在当前报告中假定任何新模型已下载或可运行。

### 7.2 弱语音、词尾及过抑制诊断

先在有干净参考的模拟数据中确定语音活动，再用干净语音的能量分位与音素/字词对齐形成切片：弱语音、非浊辅音、词尾、短暂停顿附近。对齐尽量基于干净源与人工文本，抽样人工复核；不以增强输出的ASR对齐定义评价区域，否则系统越删越可能把错误区域从评价中移除。

首轮小样本中，先人工定位疑似丢失的字词与时间段，不要求立即建立自动音素对齐、细分类别统计或新增诊断网络。若问题确认后确需大批局部分析，再决定是否引入对齐工具；并将早期发现样本与后续独立测试分开。

可定义一个**项目诊断量，而非声称新标准**：在干净参考活跃区域，统计固定频带/帧中输出幅度低于参考某一阈值的比例和最长连续时长，并扫描例如3/6/10dB的欠估计阈值。该量仅表示局部幅度欠估计；残余噪声可抬高能量，故必须搭配参考相关性、谱图及听写。若采用原TSOS，按R17的压缩谱与阈值定义复现，不能把另一套能量公式也命名为同一TSOS。

关键分析包括：

- 删除率是否下降，同时替换或插入上升；“不吞字但识别出更多噪声词”不算无条件成功。
- 词尾/辅音切片的增益是否超过普通元音；采用全句统一对齐与尺度，不为每个切片单独最优对齐以掩盖时序错误。
- 无语音帧输出能量与原噪声能量比是否变大；误回填发生在哪些噪声类别、方向与混响条件。
- 预先固定案例集：同一时轴的输入/目标/基线/改进波形、声谱图、门控图、ASR差异，以及原始可试听音频。禁止只画看起来漂亮的成功例。

音素级多通道评价本身已有先例，应引用R20。项目价值来自它揭示了哪些误差、能否解释改进边界，而不是“第一次按音素评价”。

### 7.3 可选扩展：真实录音与多人听测

本节不属于初轮诊断或最小方法验证的前置要求。根据主要不确定性选择其一：真实录音回答域迁移问题，多人听测回答人的理解问题，不能用一个替代另一个，也无需同时开展。

真实 CHiME 近讲音频不是与远场同通道、无噪且严格对齐的参考，不能直接套SI-SDR/PESQ后解释为算法失真。真实验证优先使用转写WER/CER、盲听和适用的无参考指标；RealMAN若使用估计直达参考计算有参考指标，应注明其估计与扬声器回放属性，并检查时延和尺度。

若后期选择听测，可考虑约10—15名听者、20—30段短语音的探索性盲听/听写，随机化系统顺序并平衡播放次序；把语音自然度、噪声烦扰、实际听写正确率分别记录。一次让同一听者反复听相同句子会产生学习效应，应采用分组/拉丁方或分配不同句子。测试前说明任务并取得参与同意；此规模只能支持有限结论。未做多人听测时，应写“研究者试听与客观指标”，不写成已证明人类可懂度改善。

### 7.4 对照按阶段启用，已有近邻与内部消融分开

以下C3/C4只针对第5节最终被选中的情况；改选其他方向时重写相应对照，不能为了填表而实现全部模型。

| 编号 | 系统 | 启用阶段与作用 |
|---|---|---|
| C0 | 原始带噪参考通道 | 初轮诊断：输入水平与增强前识别错误 |
| C1 | 官方权重的原McNet | 初轮诊断：核查复现，并确定疑似内容损失 |
| C2 | C1 + 验证集选择的固定全局回混 | 问题确证后：检查简单工作点调整是否已足够，无需训练 |
| B1 | 选定的已有近邻，如Bridge或BOA的可核查复现/适配 | 最小方法验证：外部方法对照；记录是否忠实实现、监督和接口差异 |
| C4 | 拟议方法；仅在证据支持时采用空间门控 | 最小方法验证：与C1/C2/B1在同一锁定测试集比较 |
| C3 | 无空间特征的同容量门控 | 若要归因于空间线索则必须补做；若B1恰好满足该控制可说明后复用，否则它不替代B1 |
| A1 | 去掉恢复上限或漏噪约束 | 后续按需：只消融最终方法确实包含的关键项 |
| A2 | 空间特征打乱/破坏 | 后续按需：进一步检查空间机制，不作为第一轮必做任务 |
| A3 | 追加训练种子 | 初步有益后先加第二次；增益很小或方差较大时再考虑第三次，不要求首轮三次 |
| U0 | 使用真值的理想受限门控 | 误抑制确证且候选A被考虑后：分析可恢复性，不计作可部署成绩 |

第一轮只需C0/C1及干净目标，不做门控训练。进入最小方法阶段后，优先完成C2、一个B1和一个候选方法；空间贡献等额外主张必须补其必要归因对照，否则收缩表述。若B1的实现/适配无法核对，不能把自己写的C3更名为B1后宣称超过已发表方法，应明确仅完成简化对照。

仅测试时打乱空间线索会制造分布偏移，下降本身不能证明机制成立。若后续做A2，应结合训练时即无空间的C3解释；不强制一次做所有打乱形式。MVDR恢复分支也不是最低版本要求；一旦加入，须补交叉对照，预算不够则不增加该分支。

### 7.5 公平比较、统计与成功标准

固定训练源语音、混合列表、训练步数、门控参数预算、损失和验证机会。各系统使用同一ASR与预处理。参数多的空间门控应与等容量无空间门控比较；提供简单固定回混的完整工作点曲线，防止只挑它的差工作点。

诊断阶段先报告明确内容损失的位置、独立语句/说话人数量及全部样本分母，指标用于辅助定位，不以某个WER阈值自动认定吞字。进入方法阶段后，再按实际问题预先指定主指标，例如**锁定小测试集的WER/CER变化与删除率**，并约束质量与噪声残留；只有另设未见噪声类型时才称未见噪声测试。验证阶段可讨论PESQ平均下降不超过0.05、SI-SDR下降不超过0.3dB等工程非劣界，但它们不是感知等价保证，必须测试前锁定，不能事后放宽。

同一源语句的多个混合不独立。首轮以逐例结果和描述统计为主，不从几十条语句外推总体发生率；方法阶段可按源语句/说话人进行配对分组bootstrap，报告置信区间并披露小样本限制。对WER重采样语句后重新累计编辑数/参考字词数。bootstrap反映测试样本不确定性，不能替代重复训练验证优化随机性；单次训练不报告“跨种子稳定”。

**分级结论：** C4仅优于C1，称“相对原基线有初步收益”；进一步优于合理工作点C2及可核查的已有近邻B1、且代价受控，才支持限定条件下的方法增量；优于C3可补充空间归因。一次训练、一个ASR、模拟小测试集仅能给出探索性结论。重复训练、独立ASR、真实录音、多人听测分别支撑训练稳定性、识别器迁移、真实域迁移、人的理解，未做哪项就不声称哪项，不能把全部扩展当作开始研究的门槛。

## 8. 本机资源与实现可行性

### 8.1 已有环境事实与尚缺条件

上一轮本机只读检查已确认：Ubuntu24.04.3 LTS、WSL2内核6.6.87.2、RTX4060 Laptop GPU 8188MiB显存、约19GiB WSL内存、20个可见逻辑处理器；Python3.12.3与Git可用。pip、完整虚拟环境支持及常用编译工具尚未就绪。本轮没有改变这些条件。

当前Codex通过Windows PowerShell调用`wsl.exe`执行Linux命令已验证；代理本身是否改为WSL运行与当前项目是否放在Linux文件系统，是另一项工作。后续确认开发模式后再规划项目存储，不在本轮迁移或覆盖目录。

**模型参数小不能保证8GB训练。** 双向LSTM、频点展开和反向激活会占内存；SpatialNet注意力随句长增加也可能迅速放大显存。冻结主体并缓存输出可以把训练显存主要留给小门控，但不消除主体生成缓存时的推理需求。ASR评分与增强推理应顺序运行，避免多个模型长期同时驻留GPU。

### 8.2 后续允许执行时的资源探测顺序

初轮只需P0/P1。P2—P4仅在问题确证、已有近邻比较计划和候选方法经审核后启用，不因本文保留了门控公式就自动进入训练。

| 步骤 | 拟定探测 | 通过标准 | 不通过时的处理 |
|---|---|---|---|
| P0 | 官方权重CPU加载与1条短句推理 | 配置匹配、输出长度/通道正确、无NaN | 定位兼容问题，未解决不进入训练 |
| P1 | 1、2、4秒片段，batch1 GPU推理 | 记录实际峰值显存、时间与输出差异 | 缩短片段；分块必须有重叠与边界验证 |
| P2 | 冻结主体、仅门控前后向 | 目标峰值保留桌面/GPU安全余量 | 减少门控尺寸、预缓存、降低精度后复核 |
| P3 | 100—500个训练step与独立验证 | 损失正常、无数值/数据泄漏问题 | 先修定义和数据，不扩大规模 |
| P4 | 锁定长度、精度、batch、缓存策略 | 能完成预算内一次训练与评分 | 缩小实验矩阵或使用最低版本 |

可从1—2秒、batch1起探索门控训练；梯度累积增加有效batch但不会降低单片段显存，也不完全等同大batch优化。混合精度须检查复杂STFT/损失的数值稳定性。离线分块会改变上下文，不能把分块基线与全句改进方法不公平比较。

### 8.3 时间与磁盘预算的估算方法

首轮诊断没有训练预算，仅需官方推理、一个ASR及少量指标计算；不能因数据少就推断训练一定适配8GB。进入方法阶段后，在P3测得平均每步耗时 \(t\)，计划更新步数 \(K\)，则基础训练耗时约为 \(Kt\)，再加验证、ASR和数据I/O。最初每个选定方法只训练1次，有趋势才追加种子或消融；不预先安排三次全套实验。几百轮原论文训练不是本科最低要求。

方法阶段可先给选定候选约1000—2000步的趋势探测预算；近邻方法应按其配方和验证收敛情况分配训练机会，不能故意少训近邻形成优势。若双方仍未收敛，只能报告资源受限探测，不当作最终优劣。主方法与最接近对照有必要时再扩至更多更新步。方向C的教师反传、全模型重训等高成本内容暂不纳入最低版本；固定回混扫描无需训练。时间先实测，再决定扩展，不给未经测量的固定小时承诺。

六通道16kHz的float32波形约1.29GiB/小时；初轮几十段短音频的实际波形与输出只占其中一小部分。总磁盘预算还取决于模型文件和数据最小下载单元，应先列清单，不再把30—80GiB缓存视为起步要求。方法阶段0.5—1小时语音及派生缓存按小样本估算，尽量只保留需要的特征，不全存多路复谱。不要完整下载RealMAN；Linux虚拟盘显示剩余容量不等于宿主机实际可再占用同等空间。

与当前硬件最匹配的起点是**官方短句推理 + 小样本诊断 + 一个ASR顺序评分**。只有后续需要时才增加冻结主体的小模块训练。不推荐从零训练声码器、多通道扩散模型或联合训练大型ASR；对SpatialNet-large完整训练也不作可行承诺。

## 9. 分阶段实施路线与交付边界

以下为审核后可采用的顺序。前两阶段完成后先审查结果，再决定后续工作；周数只是排期参考，不构成连续自动执行的授权。

| 阶段 | 预计安排 | 工作与产物 | 进入下一阶段的条件 |
|---|---|---|---|
| G0 复现准备核查 | 约第1周 | 核McNet代码/权重许可、兼容方案、数据权限，固定版本；后续获准才建立环境和加载模型 | 授权与短句推理可行；否则先解决复现问题 |
| G1 小样本诊断 | 约第1—2周 | 40—60个短混合，单ASR，无新训练；保存全体结果和逐例证据 | 得到具体候选问题；没有稳定迹象则不设计恢复模块 |
| G2 新样本确认与方法审核 | 约第3周 | 16—24个新混合确认重复性；核查最接近方法；必要时试固定回混、分析可恢复性 | 问题存在且已有办法仍有缺口，才选择一个候选改进；产出审核结论 |
| G3 最小方法验证 | 审核通过后约2周 | 小训练集、1次训练、1个ASR；原基线、固定回混、一个近邻与候选方法；120—200个锁定测试混合 | 是否值得继续、优势来自哪里；无效则保留负结果或重新选题 |
| G4 针对性扩展与写作 | 有初步收益后，按剩余时间 | 先选最必要的一项扩展：追加种子、独立ASR、少量真实录音或关键消融；整理论文 | 证据支持多少就写多少，不要求扩展项目全部完成 |

### 9.1 当前下一阶段的最低交付：问题诊断报告

1. 一个合法可用的官方基线推理复现，包含配置、权重来源、版本和资源记录。
2. 预先固定的40—60个诊断混合及少量控制样本，完整保存输入、参考、输出和一个ASR结果；不是只保留失败音频。
3. 逐例可定位的疑似问题、全体分母、明确/不确定/无问题分类，以及对复现错误和ASR偏差的排除说明。
4. 候选问题在新增样本上的确认或否定，以及“继续什么问题、是否值得设计方法”的决策。没有确认误删时，报告这一事实，不以训练模块填补缺少问题证据。

这一交付是方法研究前的阶段成果，不等于承诺单靠几十段音频就足以形成完整毕业论文。

### 9.2 方法研究的最低版本与可选扩展

如果G2通过，方法型毕业设计最低版本再增加：一个针对已确认问题的改进；原模型、简单回混、一个最接近已有方法的可核查对照；独立小测试集的质量/内容/漏噪结果；与主张对应的必要归因分析。可以先用一次训练与一个ASR，明确其探索性和训练方差未验证。不要求默认完成真实录音、第二ASR、三次重复与多人听测。

如果G2不通过，先重新审核题目与证据：可转向已实际发现的其他失效或做范围明确的复现/保真评估，不提前保证负结果本身就满足学校毕业设计要求。具体学术工作量应与导师要求核对；不能因此虚构问题或方法收益。

### 9.3 扩展版本：按不确定性选任务

先判断最小版本还缺什么证据：一次训练的小增益可能来自随机性，就优先追加种子；怀疑识别器偏置就换一个独立ASR；怀疑模拟域差才取真实小子集；若要主张人的可懂度才安排多人听写。第二次训练仍有疑问时可增加第三次，但“三次”不作为所有实验的固定配额。空间破坏、混响/坏麦与MVDR交叉消融也只在相关主张需要时启用。教师损失暂不纳入执行计划。

理想成果是一条逐步成立的证据链：**是否存在稳定问题 → 问题是什么及原因是什么 → 已有方法还缺什么 → 新改动相对近邻有何增量 → 证据能支持哪些范围内的结论。** 每次扩展都回答一个明确疑问，不以完成最多实验为目标。

### 9.4 与普通开源复现的区别

普通复现回答“官方模型能否跑出接近原结果”；本项目先进一步回答“是否有稳定且重要的内容损失、其原因是什么”，之后才研究“相对已有近邻方法是否还存在可验证增量”。问题诊断与公平比较具有研究价值，但不自动等于算法创新；只有方法和证据支持时才提出相应主张。兼容接口适配、改数据路径、做网页演示不算算法创新。

如果实验证明方法没有优于固定回混，也可以形成有效的本科结论：在指定资源与场景内，小型空间门控的收益不足以抵消误回填，简单方法更稳健。不得删去负结果后宣称全面有效，更不保证论文发表。

## 10. 最大风险、失败结果与需要进一步验证的问题

### 10.1 最大的三个风险

| 风险 | 为什么是核心风险 | 早期降低风险的动作 | 无法解决时 |
|---|---|---|---|
| **问题本身尚未确证** | 当前没有本机多段实验支持“McNet稳定误删”；ASR/对齐/域差也可能造成表象 | 先固定小诊断集、逐例排错，再用新增语句确认并报告全部分母 | 不训练恢复模块；转向实际发现的问题或重新选题 |
| **已有方法已足够，创新不成立** | BOA/Bridge/相干后滤波已有先例；胜过原McNet可能仅因回混更多噪声 | 最小方法阶段就加入一个真正近邻和合理固定回混；内部消融另列 | 若不优于近邻，明确为复现/系统分析，不主张新算法 |
| **复现与扩展成本超过资源预算** | 许可、旧依赖、数据获取、显存及过多评测均可能拖延 | 核授权与短句推理；从一个ASR、无训练诊断起；有证据才追加一次扩展 | 缩小主张与规模，报告未验证的训练稳定性/真实泛化；不隐藏基线替换 |

### 10.2 执行前逐项回答的关键问题

- McNet代码与checkpoint的具体使用、修改、论文附录/再发布权限是什么？本次只读核查不等于已取得明确许可。
- 官方offline权重与所列配置能否在选定兼容Python/Torch/Lightning组合中正确加载？兼容适配会否改变数值行为？
- 学校是否已有CHiME/LDC授权？RealMAN是否能细粒度获取所需场景与通道？将使用哪个数据版本？
- 当前选定的目标是参考通道混响语音，还是直达/早反射语音？恢复来源与评分参考是否一致？
- 原模型在匹配数据上是否存在稳定、可复核的弱语音损失？不是ASR自身漏识别、错误时延或评价参考造成的吗？
- 问题是否在未参与发现的新语句上复现？报告了全部分母，还是只展示少数失败例？
- 哪个已有方法是最终机制的最近邻？是否能忠实复现或透明适配？仅胜过原McNet时是否明确不作创新结论？
- 当前属于诊断、确认还是方法阶段？本轮究竟需要哪些证据，哪些扩展应留待后续审核？
- 理想受限恢复是否存在足够空间？固定回混是否已经达到相同收益？
- 低SNR、高相干定向噪声、近同向说话人时，空间特征还能否正确指向目标？没有高可信语音锚点时怎么退化？
- 训练与测试的源语音、噪声录音和RIR是否真正分离？官方预训练数据是否与测试重叠？无法核查的部分怎么披露？
- 1/2/4秒推理和门控训练的实际峰值显存是多少？全句或分块能否在公平条件下处理？
- 主指标、非劣界、语音活动规则、分词/文本归一化、测试样本抽取与统计方法能否在测试前锁定？
- 有无与本方案更直接重复的“空间约束自适应OA/残差恢复”论文？本次调查已发现近邻，不能据此证明全世界不存在相同方法；方法定稿前需再围绕具体机制查重。

### 11.3 核查范围、复现记录与报告边界

本研究分为模型/仓库、内容保真先例、数据/指标三组主题；采用搜索发现后再读原始页面、作者稿、README与配置的方式核对。可计数的主流程与两条模型核查工作流合计请求了159条Exa候选结果（含重复；不是159篇独立论文或全文精读计数），内容先例工作流另提供了交叉核查。对结果按同一论文、同一仓库合并，不按搜索命中次数增加证据权重。
