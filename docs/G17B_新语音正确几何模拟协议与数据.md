# G17B 新语音正确几何模拟协议与数据

源/排除记录先保存后，生成8句/4位项目新说话人的正确几何模拟：OOFFICE/NPARK旧录音，0dB，三目标角−40/20/70、两点源相对方位−80/+25及八源叠加；144带噪+24干净=168条件/系统，21系统3528条/后端。完整语句加128样本保护，不截字。

采用已核查的rotate_azimuth；每个目标/噪声点积保持，点源实际相对角全部核验；56组第5麦带噪及干净参考跨目标方向逐样本相同。共用片段、防削波尺度；噪声40Hz高通后活动帧SNR。仅名义六麦自由场，不是房间混响或真实阵列。

噪声片段固定在250—295秒、八源在互不重叠子窗选取，与G5/G15全部LoRA训练噪声片段不重叠；OOFFICE录音在适配训练中出现过，NPARK没有但已用于本项目旧测试。不是新的独立噪声录音，原McNet预训练曝光未知。

冻结原模型、固定/反向/刚性各三种子(全部3000步)，并加10个对应成熟MVDR输出；不按新语音结果筛方法、种子或角度。来源源SHA/话人ID排除和方法冻结先于任何新评分；语句/条件/种子不能当数千个独立样本。后续按方向、噪声、场型、每说话人/种子及干净控制保留负结果。
