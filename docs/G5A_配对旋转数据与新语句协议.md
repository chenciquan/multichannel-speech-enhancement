# G5A 配对旋转数据与新语句协议

G4报告和审计保存后开展。使用同一2,048个源语音裁片、噪声时间段、源方向种子和SNR，重新生成固定场景与整场景旋转两套配对训练数据。全部声源共同旋转，目标方位均匀分布−45至75°；人声与噪声相对关系保持。每对共享防削波尺度，第5麦带噪样本和干净目标完全相同，已逐例断言。每套含128个对应干净训练片段。

验证为原验证集两位说话人各3句，三种目标方向×两种点声源相对方向/八源叠加，OOFFICE 0dB，共54例，所有组共用。

新确认集从官方有界流取3位此前完全未出现的说话人，各4句，1—3.8秒。全部G1/G2/G3说话人和源文件哈希排除。目标−40/20/70°，两种噪声，点声源相对−80/+25°或八源叠加，0dB：216个带噪条件及36个干净输入。仅语句/说话人是独立新增，噪声仍是原录音的后段，不能声称全新独立录音。

比较固定/旋转×干净约束有/无，均衡采样、rank4、3584参数、FP32、3000步；按相同54例验证规则选检查点。至少完成一整组四单元种子，后续整组只由剩余时间决定；全部选权重和训练报告保存后才打开确认集。旋转增强是已有思路，不冒充新模块或创新。
