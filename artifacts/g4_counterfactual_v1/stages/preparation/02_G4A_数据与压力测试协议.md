# G4A 数据与压力测试协议

G3报告及审计已保存后启动本阶段。本阶段不训练，冻结原始McNet和G3首种子的四种适配器，另有带噪参考。

选取旧保留测试的8句、4位说话人，按说话人/语句ID轮询；它是同源探索性压力测试，不是独立新测试。核心288例将目标方位−30/20/60°、噪声方位−60/45°、SNR−5/0/+5dB、两种噪声完全交叉；另64例固定通道增益/同步偏差、24例干净输入。

为避免相对角度变化被误解为绝对方向过拟合，在模型推理前增补登记96例整体旋转对照：目标与噪声同转、相对方位固定−80/+25°，SNR0。阵列各向异性仍然存在，因此不能单凭它证明过拟合机制。合计472例/系统、6系统，共2,832信号对及对应ASR评估。

同源/噪声/SNR组使用同一噪声片段及共同防削波尺度；改变其他麦克风空间关系时，第5麦带噪样本和干净参考的哈希必须逐组完全相同，已在构建中断言。增益与同步偏差不作用于参考第5麦；同步偏差为零填充固定采样延迟，不是时钟漂移。

仅名义阵列自由场平面波，无混响或真实硬件泛化结论。所有方案固定为种子20261112，不挑选最佳测试种子。信号指标报告先保存，再运行固定tiny.en；本阶段报告及审计保存后才进入后续阶段。
