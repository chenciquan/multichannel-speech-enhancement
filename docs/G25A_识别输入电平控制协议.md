# G25A 识别输入电平控制协议

预先固定目标RMS=.05、峰值上限=.95，取两个正比例系数的较小值，无削波。参数是本次评估控制约定，没有根据WER选择。只改变送入ASR的副本，增强模型、原音频、原ASR和RMS/NMSE指标均保留。

保留G24全部480基准。先逐一验证原幅度/半幅/四分之一幅/重复原幅度经标准化后的float32完全相同；每个基准只保存一个规范化输入，并计划两遍独立识别，共960观察/后端，不把相同输入别名计为新的独立句子。预处理ID和参数另存，不与raw-ASR成绩混并。

4项数学/边界测试先运行并保留日志。控制只检验全局电平混杂，不能修复内容、改变信噪比或证明增强方法更好；不作最优电平、部署或人耳可懂度结论。
