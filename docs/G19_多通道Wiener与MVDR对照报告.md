# G19 单房间多通道 Wiener 与 Souden MVDR 配对实验

固定 10 个前端，在相同 504 个房间条件上比较直接输出、Souden MVDR 和 μ=1 的多通道 Wiener 滤波（MWF）。两种滤波器取同一神经估计、带噪六通道、STFT 与参考麦克风（从零计数为 4）。MWF 以共同帧数归一化两个互补掩码协方差，MVDR 分别按各掩码时间和归一化，因此差值涵盖协方差估计和滤波求解。

8 句语音来自先前已使用的 4 位说话人。模拟覆盖一个固定房间、两段噪声录音、三个目标方向，带噪语音活动段 SNR 为 0 dB。目标是参考麦上的混响干净语音，请求 RT 表示生成器参数。原始 McNet 每格有一个前端，固定、反向、刚性训练策略各保留三个种子。
