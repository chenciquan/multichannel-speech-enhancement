## 6. G13 纠错的真实影响

坐标为 x 右、y 前、z 上，正方位向右，`az=atan2(x,y)`。旧 `g5_prepare.rotate` 使用数学 xy 正旋转，导致目标方位增加而噪声减少，改变相对几何。G13 用 24 个保存输入及 3 条训练数组重建确认实际执行过错误。

必须撤回“G5 rotated 是几何保持旋转”的解释，但旧音频、权重和相应测量依然是实际执行证据。G7/G10 相对角标签有错，不能直接据它们解释正确刚性泛化；同输入滤波比较、新说话人排除等事实不因此消失。G2/G3、G4 的相关独立实现不受此错误影响。

G14 只修测试几何；G15 才配对修正训练。新实现 `rotate_azimuth` 使用 `x′=cosδ·x+sinδ·y, y′=−sinδ·x+cosδ·y`。详见 [G13权威更正](G13A_旋转坐标审计与历史结论更正.md)，不得只引用旧报告省略更正。

G35 补充：当前远场时延用 `p_m−p_ref`，参考麦每源时延恒零；同片段/同增益/同尺度时跨角参考可自然相同。这只是模拟约定的派生检查，不能复制/替换通道强求一致；真实阵列/RIR 不必满足。同角跨模型必须共用完全相同输入/参考与尺度。
