# G19 后的研究判断

截至 G19 验收，当前更适合把论文问题表述为“复杂声场下的轻量适配、空间滤波与语音保真权衡”，而不是先假设存在吞字再设计恢复模块。

已有证据：

- G1 的 13 次明确辅助试听反馈没有发现明显听感退步。尚无稳定人声误删的证据，ASR 的删除计数不等于声音被删。
- 27 次成功的标准低秩训练累计 81,000 次更新；这是固定 McNet 的小参数适配，不是复现官方完整训练。
- G13 发现并更正旧旋转解释。正确刚性旋转经过重训和新说话人确认，尚未显示稳定优于旧反向训练。旧结果保留，不能把反向变化称为保持相对几何。
- 成熟掩码 MVDR 经常改善已有前端，但存在方向、噪声及混响条件的权衡。单房间强反射压力下，很多配置明显退化。
- G19 固定 μ=1 的成熟 MWF 对照未形成整体优势。72 个细分条件中 23 个 SI-SDR 更高，0 个同时降低两个识别器的 WER；不可通过只报告部分指标宣称胜出。

当前 G20 先还原原房间的真实模拟分量，再固定原有滤波权重，分开观察语音误差与残余噪声。这是解释性诊断，不是新算法，也不能定位词语是否丢失。

后续优先顺序：

1. 验收 G20 全部预定条件与种子，检查误差交叉项，判断现有退化伴随什么分量变化。
2. 如继续检验声场稳健性，先固定原有方法和参数，在新的房间配置上做小规模配对确认。新的房间不等于新的说话人或真实麦克风录音。
3. 只有在重复出现的具体不足与适当成熟对照都明确后，才设计下一项改进。可讨论空间训练分布的可控变化，不能把现有 LoRA、门控、回填或空间信息直接当创新。

研究贡献是否成立，仍取决于后续受控实验与已有方法比较。现阶段可交付的是可追溯基线、轻量适配、成熟对照、负结果和保真评估体系；不保证提出有效新算法或发表论文。
