# G34 统一精度的全参数强对照：准备草案

状态：G32及G33B诊断已完成；G33原前向等价门槛仍未通过。本文件不代表新训练已经执行，具体脚本、初始检查与预算须在运行前冻结。

## 要回答的问题

目前LoRA及不同监督目标有对照，但没有在相同数据上验证全参数微调这个成熟强基线。不能仅凭3584个开放参数就声称显著节省显存/时间、质量更好，或把全参数训练假定为8GB不可行。G33两模式确已算出有限梯度，但它的原数值门槛未过；G33B补充了后端与输出接口证据。

下一项只比较原cIRM目标下的适配方式与有限学习率点，**不扩大未通过G31门槛的统计辅助训练**。所有目标与适配组件均为已有方法，结果不能直接认定算法创新。

## 执行配置与初始化边界

- 明确统一FP32、cuDNN启用、cuDNN及matmul的TF32许可关闭、benchmark=False、cuDNN deterministic=False，固定PyTorch2.5.1+cu121与种子20261113。均为进程内设置，不改系统驱动或环境。
- 同一官方McNet CP、同一完整基础参数摘要。LoRA仍为两处空间FC rank4/alpha4、零B残差。全参数组开放原模型3328706参数，结构不改。
- G33B在该配置下的重建波形六条均通过事前固定容差，压缩cIRM仍有三条未通过。旧门槛与残差保持原记录，不能改成“cIRM完全一致”或“原G33已过”。
- 新实验以基础权重摘要、零残差初始化与模型源码验证确认初始模型；另外登记相同训练输入的波形接口核查，沿用G33B的rtol=1e-5/atol=1e-6。若新运行破坏该接口，先停下来定位，不放宽阈值。中间cIRM数值残差单列，不将微小差异未经检验地当成对训练/ASR无害。
- 由于执行精度约定变化，必须重新训练普通LoRA原cIRM匹配组；旧G30原cIRM权重只作历史证据，不能当作完全匹配的新基线。

## 后续如何比较

完成训练验收后，再冻结开发评价：相同G29的108开发条件，重新运行统一精度下的未适配McNet、匹配LoRA和三个全参数学习率点，保留直接/MVDR/MWF、全部噪声/干净条件、SI-SDR/PESQ/STOI与干净RMS/NMSE。

全部学习率点并列，不按单一指标宣布“全参数最佳”；可以报告质量—资源权衡及开发Pareto关系。中心裁剪不做整句WER，G32只有四条旧开发整句/16词，不能拿它挑学习率并宣称新说话人泛化。新完整语句确认和真实阵列验证须另设来源隔离与预算。

有限学习率、单种子、小训练池与模拟房间仍是关键限制。即便某个点更好，也不能保证能发表论文、已解决吞字、或小参数方法优于充分调优的全参数方法。
