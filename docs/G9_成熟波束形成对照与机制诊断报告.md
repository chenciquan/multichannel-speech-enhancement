# G9 成熟波束形成对照与机制诊断报告

## 范围

G8验收归档后冻结协议，G9A五项前置检查及G9B信号报告均在后续步骤前保存。新增3系统×900条件=2,700条信号、每识别器2,700条评分。与旧14系统合并17系统，每后端15,300行；源句仍仅12句/3人。G5/G7已查看条件上的探索性比较，不是新盲测或真实录音验证。

主对照mcnet_mask_mvdr仅使用六通道带噪输入及原McNet估计。oracle_ref_mask_mvdr使用干净参考估计掩码，oracle_doa_delay_sum使用真实方位；两项为特权信息诊断，不是公平盲方法，也不保证数值上优于所有估计方法。无新训练、依赖、语料或权重。

## 解释、风险与审计

若估计掩码MVDR已优于轻量适配，则不能只凭优于原McNet认定改进价值；应如实保留更强成熟基线。若只有oracle改善，可用于提示掩码或方位信息限制，但不能直接推导可部署效果。所有条件上的模拟阵列/无混响假设仍限制实际应用价值。

本阶段没有新的人工吞字标签，也没有新颖性证据。全部原权重和已有识别证据冻结；主对照输入来源、2,700条新结果、双ASR覆盖/重计分、音频哈希和阶段归档顺序审计为ok。数值异常不回填；有效行均真实计分。
