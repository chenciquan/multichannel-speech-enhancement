# G31A 开发信号与干净语音评价

评价规则已在G30任何训练前写入配置并冻结哈希。本阶段使用G29全部108开发条件，无ASR；原噪声直接输入108、四个神经系统各直接/MVDR/MWF共1296，合计1404记录。三个适配组统一G30登记1500步，不按开发成绩改选。

主比较是72个带噪条件的MVDR：统计监督组对原重建组和简单掩码组均需平均SI-SDR提高至少.25dB、PESQ/STOI不降；36个干净MVDR条件的平均NMSE增量均不超过.02；每位开发说话人相对原重建组平均SI-SDR不降。此门槛仅决定是否扩展实验，不代表显著性或创新。直接/MWF及全部RT/场型/说话人结果保留，不能替换失败的主比较。

12条旧验证语句、两位说话人的中心裁剪及模拟开发房间，不能按108个独立语音样本计算显著性，不做整句WER或新说话人最终确认。保存原电平FLOAT音频、相同信号指标、干净RMS/NMSE，无拟合对齐、自动幅度恢复或重采样。3600秒上限，不训练、不下载。
