# G27C 真值掩码双识别器原始与电平评分协议

对864条新增诊断输出分别做raw和固定G25/G26电平控制评分，两个固定识别器各1728行。两种输入条件的缓存分开，分别由已验收G22/G26的完整评分表按精确PCM建立；同PCM、同模型、同解码与同预处理才复用。参考音频逐例核对真实输入哈希，不按相同文本或房间标签复用。所有新规范化输入键在解码前冻结，未缓存波形实际前向。

比较McNet掩码、真值功率比掩码和真值协方差。后两者含真值，均不可部署；不选更低的ASR条件替换另一条件。识别S/D/I与人声声学遗漏分开解释。共享3600秒上限，原增强/滤波输出与质量指标不变，无新训练或超参选择。
