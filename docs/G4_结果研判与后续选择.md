# G4结果研判与后续选择

G4报告、2,832对结果及完成审计已保存。整体旋转对照中，普通适配在目标20°为4.00dB、−30°为−2.54dB；固定噪声角度与干净输入也出现方向敏感性。这里仅一个种子、8句同源诊断，不能直接声称普遍过拟合或真实吞字。阵列各向异性与训练方向的作用尚未完全分离。

WER可以超过100%：插入词较多时，(替换+删除+插入)/参考词数没有100%上限。G4中252.7%等值必须结合插入计数、识别文本与试听检查，不能解释成“252.7%的人声被删除”。本轮没有新增人工听感判定。

G5优先验证成熟强对照“整场景方位旋转增强”：目标与所有噪声方向一起旋转，保持相对方向、语音内容、噪声片段和SNR配对。再将干净重建约束作为另一因素，避免把数据增强效果算成约束模块创新。方案在训练和新确认数据评估前登记于`configs/g5_rotation_plan.json`。

确认数据应另取3位新说话人、每人4句，且不与此前任何研究说话人重叠；若有界获取失败，不回用G3/G4语句冒充独立确认。每阶段先保存报告和证据，再进入下一阶段；总截止仍为北京时间05:54:15。
