# G7A 新噪声迁移协议与数据

在G6报告与审计归档后登记，不训练或选择新权重。固定G5全部12个适配器（三种子四单元）、原McNet和带噪参考，共14系统。复用G5的12句、3位说话人，因此是同源新噪声压力测试，不是新的说话人确认。

新噪声仅取NPARK与PSTATION的ch01。官方[DEMAND记录](https://zenodo.org/records/1227121)已核实文件及CC-BY-SA3.0；HTTP206有界范围提取、成员CRC及本地SHA256验证，没有下载全ZIP或核实整包MD5。两文件此前未用于本项目训练/评估，不能推断原始预训练模型从未见过类似环境。

目标−40/20/70°、SNR−5/0/+5dB、两种点声源相对方位−80/+25°和八源叠加，全部交叉：648例/系统，预期9,072个信号和ASR对。噪声先固定40Hz高通，再按活动语音标定SNR；共同旋转场景，成组共享片段和防削波尺度。逐组断言参考第5麦和干净参考样本完全相同。

主分析逐噪声/SNR/方向报告旋转减固定，不能只引用非训练方向平均数。点声源条件占2/3，八源占1/3，另报告分组和每说话人样本数。保持原tiny.en和解码选项，WER不截断；大于100%或插入过多只标记识别退化候选，不自动诊断真实吞字。原G5干净输入结果不重复当新证据。

仅名义阵列自由场模拟，不是新的真实六通道语音数据。所有噪声来源、文件与清单哈希、模型路径、运行代码留档；信号报告保存后才进入ASR，完成报告和审计保存后再推进。
