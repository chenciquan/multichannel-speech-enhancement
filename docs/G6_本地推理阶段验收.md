# G6 本地推理阶段验收

G6A资源与G6B独立CLI均已完成并分阶段归档，原G3—G5结果不改。

- FP32、batch1下，1秒纯GPU计算约31—35ms，3秒约83—94ms，RTF约0.03；峰值分配显存3秒约1.37GiB，Torch缓存约2.7GiB，系统开销另计。这不是流式低延迟结论。
- 五个GPU CLI结果与G5保存波形逐样本一致，最大差0；CPU原基线最大差约2.79e-4，小于预定1e-3兼容界限。
- 独立进程墙钟约25—29秒，包含库导入、初始化、核验、加载和IO；不得用纯计算数值代替使用者等待时间。
- 全套62项单测通过；随后接口9项定向复核通过，其中2项新增，覆盖未知系统与篡改权重在加载前拒绝。两日志有重叠，不相加称为71项。
- 实际二次CLI验证拒绝覆盖；音频/报告分路径、形状、采样率、有限值、长度、注册清单与模型哈希均检查。
