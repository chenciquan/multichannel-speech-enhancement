# G22A 匹配电平的新房间确认协议

4位既有说话人各第一句。原房间6×5×3m、新房间4×3.5×2.8m，参考麦位于各自水平中心、高1.4m。麦阵形状、源距1.5m、相对方向、噪声片段、三个请求RT及目标方向不变。全部真实RIR、实测T20外推和末端能量保存，不把请求RT当实测T60。

两房间共用跨18个变体的防削波尺度；重新渲染原房间，消除单独选尺度的电平差异。旧尺度下的原房间须逐样本还原旧输入和参考。新共同尺度下，RT0两房间输入/参考差须不超过一个PCM24 LSB，提前固定不根据成绩调整。

共504条件（每房间216带噪+36干净）。先物理检查和数据归档，不运行模型/ASR。未来比较保留全部三种子、全部成熟滤波对照，真值统计始终单独标记。只有一个新增房间，不能声称广泛房间泛化。
