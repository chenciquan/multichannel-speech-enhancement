# G28 v1：CPU 数学预检的复数类型错误

v1 在首个训练记录的 CPU complex128 有限差分检查中停止：`einsum` 的复数频谱与实数掩码未统一 dtype，PyTorch 报错要求矩阵乘法输入类型相同。失败发生在模型加载之前，优化器更新为 0；没有产生有效梯度结果，不能把此运行计作预检通过。

原脚本 `scripts/g28_gradient.py`、冻结计划、协议快照及 `artifacts/g28_gradient_feasibility_v1/failure.json` 全部保留。v1 的临时唤醒助手未成功启动：首次检查时输出目录尚未出现，保护条件拒绝了启动，未改变电源计划。

v2 单独保存在 `scripts/g28_gradient_v2.py` 与 `artifacts/g28_gradient_feasibility_v2`。数学修正仅为在协方差收缩运算时把实掩码显式转换到频谱的复数 dtype，虚部仍为 0；该转换保留对原实掩码的梯度。训练记录、目标公式、随机种子、有限差分容差和无参数更新要求不变；v2 独立冻结和验收。报告路径更名以免覆盖 v1。

这是实现错误的修复，不是因指标不好而换条件重试。v2 是否通过，以其实际结果为准。
