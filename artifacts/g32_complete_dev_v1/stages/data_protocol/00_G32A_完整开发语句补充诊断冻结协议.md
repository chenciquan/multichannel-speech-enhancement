# G32A 完整开发语句补充诊断协议

来源在G31科学读回前已按原清单每个旧开发说话人前两条、长度≤56320样本选定，共4条、2人；合计16个原始转写词token，很小，不代表群体识别准确率。整句不裁剪，加7680样本全卷积尾仍≤4秒。

复用G29开发房间及RIR，三请求RT(0/.16/.28)×点源/八源/干净，共36条件。源序号奇偶配−30/+30目标、OOFFICE/DKITCHEN，点源相对−80/+25和SNR0，八源SNR−5；每位说话人含两个方向。噪声只在[125,175]秒块内独立高通，保留完整1秒预滚/尾部区间和1秒块内边界；八源片段互不重叠。每例混合与全六通道目标共用防削波尺度，输出FLOAT WAV，活动SNR容差.001dB。

冻结原McNet及G30三组登记1500步、直接/MVDR/MWF与原带噪输入，共468信号。数据与信号先验收，再现有两个固定识别器raw及固定G25/G26电平控制分别评分，各936系统记录；另列四条原干声的双条件参考识别，辅助判断固有识别/拼写错误。无需新训练、依赖或下载。参考转写只用于评分，不作识别提示。

是旧开发角色的补充诊断，不是未见说话人最终验证，不覆盖或重判G31未通过的主门槛。新波形与原1秒裁剪的噪声区间、尺度及SNR标定可能不同，不把两轮差值单独归因于上下文长度。两个识别器的S/D/I不当作声学吞字。完整语句仍很短、含人名和非标准语法，需对照原干声及混响参考识别，不改原转写/拼写来降低WER。
