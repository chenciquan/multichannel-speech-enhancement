# G11 固定MVDR的目标语音与残余噪声诊断

## 能回答什么

在G10已评估16句/4人上，重建模拟干净六通道，取N=X−S。只用原带噪输入与旧神经估计重算每个已冻结MVDR滤波器，确认旧输出后固定W，分别计算W作用于S与N的响应。真值不参与掩码估计，不产生新的可部署oracle增强器；不训练、不下载、不重新识别。

7前端×576带噪条件=4,032条：原始前端576，固定/旋转前端各三种子1,728。保留全部种子。该分解只针对已确定的线性滤波器，不能直接分解非线性神经网络的直接输出，也不能据此证明某个词/辅音被删除。它有助于解释目标失真与噪声压低的区别，不是新增强算法或独立新测试。

## 指标定义

目标失真NMSE=mean((目标分量输出−干净参考)^2)/mean(干净参考^2)，小者好，包含尺度误差；目标增益=10log10(输出目标功率/输入目标功率)，0dB是总体能量保持，但不保证细节；噪声衰减=10log10(输入噪声功率/输出噪声功率)，大者好；分量SNR比较的是输出目标和残余噪声功率，必须与失真一起读。全句功率不等于原活动语音标定0dB。

表内NMSE为逐例比值的算术均值；dB为逐例dB均值，并非合并功率后的比值。纯增益衰减可能几乎不影响SI-SDR，所以另列目标增益。1e-30功率下限及未定义目标SI-SDR显式记数；权重范数只作白噪声功率放大诊断，不当作未经验证单位目标响应下的WNG。

## 完整性、边界与后续

全部4,032条参考重建误差为0；最大旧输出复现误差0.0，最大线性误差5.960464477539063e-08。输入、估计、旧输出、源FLAC、原始主干与六适配器哈希通过，原ASR计分仅关联未重跑，CUDA未初始化。审计：ok。

量化S后定义N=X−S，N包括混合/干净量化差额；这与假设拥有无误差真实录音分量不同。能量保留或失真不等于音素/语义保留，旧WER仅并列展示，不据相关性作因果断言。直接神经输出与MVDR之间的全部差异仍不能由本分解完全解释。仅首批合成阵列/0dB/四录音/四说话人，缺真实混响、实际硬件与新的人工盲听证据。

如果某组通过更少压低噪声换来更少失真，应如实称为权衡；若同时改善，需要在其他独立环境继续确认。不能从机制诊断直接宣称LoRA＋MVDR的新颖性。接下来的算法选择应先依据失败条件与已有研究对照，不能把本批重新当未查看最终测试。
