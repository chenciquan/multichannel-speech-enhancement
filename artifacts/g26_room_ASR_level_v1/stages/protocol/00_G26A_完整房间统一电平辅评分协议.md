# G26A 完整房间统一电平辅评分协议

对原G22全部16488输出和504个参考条件固定使用G25规则与同一预处理ID，模型、解码选项和增强参数不变。原音频、raw-ASR及质量指标不改。统一电平ASR另存为辅助评价条件，不选择更低分覆盖旧表。

规范化在内存中重建，清单保存原文件SHA、规范化PCM SHA、预处理ID与增益诊断，不再复制整套音频。仅复用同一预处理的相同PCM输入；未缓存输出及参考必须解码。先数据/哈希报告归档，再执行固定两个识别器。

分析保留所有三种子、方向、噪声、场型、干净控制和房间配对，特别检查主要方法排序和原有房间效应是否保留。后验辅评分不能称未见数据验证或新的增强算法。四人四句的统计限制不变。
