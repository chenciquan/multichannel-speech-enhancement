# G1 小样本诊断数据规范

本规范先约定数据，后观察模型结果，避免根据失败音频反向挑选评价集。截至2026-11-11，已冻结`data/diagnostic/g1_v1/manifest.jsonl`：24条完整语句、6位说话人、48个模拟六通道混合。自动推理与评价已完成，全体逐词判定和独立确认未完成。实际协议见`configs/g1_protocol_frozen.json`，自动诊断交付时的结果与限制见[G1首轮诊断报告](G1_首轮诊断报告.md)。

后续补记：7条ASR候选及6条预先固定的正常对照已有用户辅助试听反馈，均未报告明显退步；不是全48条逐词判定，未通过稳定失效门槛，未进行新增语句确认。记录与路线决定见[问题核查与阶段决策](G1_问题核查与阶段决策.md)。

## 规模与用途

初轮20—30条源语句，4—6位说话人，每句2个条件，共40—60个短混合；2类噪声、0/5dB均衡分配，固定同步六麦阵列、无/低混响、一个语言、一个固定ASR。具体公开源文件、许可证、几何与噪声生成方案应在生成前登记。

问题确认另用8—12条新增源语句；诊断与确认数据用来选择问题，不能再次冒充最终独立测试集。单个ASR删除词只标记疑似，不自动认定模型吞字。

本轮为LibriSpeech dev-clean英文语句及DEMAND DWASHING/DKITCHEN单通道噪声的几何重传播；无混响，固定远场方向，不保留原DEMAND空间场，不是官方CHiME测试集。两种噪声×两档SNR各12条。源语句、说话人和噪声录音不因生成多个条件而变为新的独立样本。

## JSONL字段

每行一个对象，字段如下。以下是字段说明，不是伪造样本。

| 字段 | 类型/取值 | 说明 |
|---|---|---|
| sample_id | 非空唯一字符串 | 一个混合的ID |
| source_id | 非空字符串 | 原始源语句ID，不随噪声/SNR改变 |
| speaker_id | 非空字符串 | 原始说话人ID |
| split | discovery / confirmation / train / validation / test | 用途，源语句不得跨split |
| noisy_path | 路径字符串 | 六通道同步16kHz WAV，相对路径以清单父目录为基准 |
| reference_path | 路径字符串 | 单通道16kHz、与输入等长的参考目标 |
| transcript | 非空字符串 | 来自数据集或人工核对的文本 |
| noise_id | 非空字符串 | 应追溯到原始噪声录音，不只标“键盘”等类别 |
| snr_db | 有限数值 | 按协议定义的参考通道SNR |
| sample_rate | 整数16000 | 不自动重采样 |
| ref_channel | 整数4 | 零基索引，第5麦克风 |

可增加`dataset`、`source_url`、`license`、`room_id`、`array_id`、`noise_type`、`mix_seed`、文件SHA256等字段。首次使用具体公开数据前，应把来源与许可记录完整。

## 自动检查与人工检查的边界

标准库校验器检查必填字段、重复ID、源语句跨split、训练与验证/测试说话人泄漏。`--check-audio`额外检查整数PCM WAV的通道数、采样率、等帧长及截断。它不支持FLOAT WAV；增强输出FLOAT WAV不作为该输入清单的`noisy_path`。

通过文件头检查，不能证明阵列真实性、噪声/RIR划分或授权。必须另行核对：

1. 六路是否来自同一物理一致传播过程；复制单麦、六路独立随机信号不是有效的真实语音阵列样本。
2. 参考是参考麦语音图像还是直达声；不能混用目标来诊断词尾丢失。
3. 同一噪声长录音和房间/RIR是否跨了需要独立的划分。
4. 官方预训练数据与本次测试是否有未排除的重叠。

## 逐例诊断记录

至少记录：样本ID、目标文本、疑似字词及时间段、干净参考/带噪输入/McNet输出的可试听路径、ASR三路结果、对齐与尺度核查、判定（明确/不确定/无问题）、判断理由。报告全体分母，不只发布成功或失败个例。

当前核查入口为`artifacts/g1_v1/review_v2/index.html`及同目录`review_all_cases.csv`。CSV包含全部48条，所有`listened=False`、`human_verdict=not_assessed`；请另存工作副本后填写。页面不自动保存判定。带噪试听是第5麦的无增益/无重采样FLOAT副本，已逐采样核对，不让浏览器自行混合六路；旧`review/`仅作追溯。人工核查未做时，确认例数应为“未判定”，不能把null写成已证实0例。

独立确认前先冻结失效描述。发现批跨多条源语句/说话人重复出现、确认批新增语句再次复现，才讨论方法设计；这些操作门槛不是总体发生率的统计证明。

## G2补充：频谱与空间条件确认

原噪声存在极强的约16.4Hz分量，全频SNR不能代表语音频段难度。后续须同时记录频谱、全频活动SNR与明确频段的带内SNR，不修改旧清单的定义来美化结果。

`data/diagnostic/g2_confirmation_v1/manifest.jsonl`为8条新完整源语句、128个条件混合，split为confirmation；ID及源文件哈希与原24条均不重合。空间条件对比中，同一源语句/噪声/频谱条件的参考麦带噪波形完全一致；噪声频谱干预则有意改变参考噪声并重新标定SNR。两个随机种子仅改变条件12波场，不是新增语句或训练种子。

新噪声片段与原24条使用片段及其他新语句片段不重合，保留4000采样点间隔；各因子与种子复用同一片段以支持配对。两段噪声仍来自原来的两个长录音，不能称为未见录音/噪声类型。说话人仍为原6位，不能声称未见说话人泛化。

新规则已确认当前模拟条件中的质量退化，非人工吞字事件。G2结果与方案见[G2报告](G2_原因分析与改进方向.md)。最终方法测试必须排除目前全部诊断/确认源语句，并在训练前锁定说话人、噪声录音/片段、方向与数据划分。
